# Security

## Reporting a vulnerability

Please open a private security advisory on this repository (GitHub → Security → Report a vulnerability) rather than a public issue. We aim to respond within 7 days.

## Threat model and controls

| Threat                                 | Control                                                                                                                                                                                                                                                                       | Where                                                              |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| API key leakage                        | Gemini key is read only on the server (`server-only` guard), never sent to the browser, never committed (`.env*` ignored; `.env.example` has no secrets)                                                                                                                      | `src/lib/ai/model.ts`                                              |
| Abuse of the AI quota                  | Per-client sliding-window rate limit (12 AI calls/min by default) keyed on the platform-set `x-real-ip`, never the spoofable left-most `X-Forwarded-For`                                                                                                                      | `src/lib/security/rateLimit.ts`                                    |
| Malformed or hostile input             | Every request body and query is size-capped (32 KB) and validated with Zod; names accept only letters (any script), digits and light punctuation; invalid values are never echoed back                                                                                        | `src/lib/api.ts`, `src/lib/schemas.ts`                             |
| Prompt injection                       | Fixed server-side system rules; user text is wrapped in `<user_message>` and sanitised (control, zero-width and bidi-override characters removed); the model is told such content is data, not instructions                                                                   | `src/lib/ai/prompts.ts`, `src/lib/security/sanitize.ts`            |
| Hallucinated or manipulated figures    | Model output must match a Zod schema **and** pass a grounding check: significant numbers must exist in the engine's fact sheet, otherwise the deterministic plan is used                                                                                                      | `src/lib/ai/grounding.ts`, `src/lib/ai/generate.ts`                |
| XSS                                    | Model output is rendered as React text, never as HTML (no `dangerouslySetInnerHTML` anywhere); strict nonce-based CSP with `strict-dynamic`, `object-src 'none'`, `base-uri 'self'`, `frame-ancestors 'none'`                                                                 | `src/proxy.ts`                                                     |
| Clickjacking, MIME sniffing, downgrade | `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, HSTS (2 years, preload), `Referrer-Policy`, `Cross-Origin-Opener-Policy`, minimal `Permissions-Policy`                                                                                                            | `next.config.ts`                                                   |
| Cross-user data leakage via caches     | Air data is cached per ~1 km grid cell without any requester data; AI output is cached under a SHA-256 of the complete prompt input, so it is only reused for identical requests                                                                                              | `src/lib/air/openMeteo.ts`, `src/lib/services/assistant.ts`        |
| Upstream failures leaking internals    | Upstream errors are mapped to generic messages; stack traces and upstream bodies are never returned; logs record only error names/messages                                                                                                                                    | `src/lib/http.ts`, `src/lib/api.ts`                                |
| Privacy                                | No accounts or database. The household profile lives only in the browser's localStorage and is validated on read. Coordinates are rounded to ~1 km before leaving the browser.                                                                                                | `src/lib/client/profileStore.ts`, `src/components/PlacePicker.tsx` |
| Unsafe health guidance                 | Rules forbid masks for under-2s, require emergency escalation (112) for red-flag symptoms, and a "not medical advice" notice is always visible; Gemini safety filters block high-probability harmful content (medium was measured to block legitimate child-health questions) | `src/lib/engine/risk.ts`, `src/lib/ai/model.ts`                    |
| Vulnerable dependencies                | `npm audit --omit=dev --audit-level=high` runs in CI on every push                                                                                                                                                                                                            | `.github/workflows/ci.yml`                                         |
